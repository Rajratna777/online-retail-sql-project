# Online Retail Database Management & Analysis

## 📌 Project Overview

This project involves designing and analyzing an Online Retail Database using SQL. The database represents a retail business with information about customers, sellers, products, stores, orders, payments, deliveries, and product reviews.

The main objective is to use SQL to explore retail data, answer business questions, and generate meaningful insights that support business decision-making.

## 🛠️ Tools & Technologies

- MySQL 8.0+
- SQL
- MySQL Workbench

## 🗄️ Database Structure

The database consists of multiple related tables covering the following areas:

- **Users:** Buyers and sellers
- **Products:** Product details, brands, categories, and inventory
- **Stores:** Store information and management
- **Orders:** Orders, order items, and shopping carts
- **Payments:** Payment details and bank cards
- **Delivery:** Customer addresses and order deliveries
- **Reviews:** Product ratings and customer comments

## 📊 SQL Analysis & Concepts

The project covers basic to advanced SQL concepts:

- Data retrieval and filtering
- Aggregate functions and grouping
- INNER, LEFT, and RIGHT JOINs
- Subqueries and correlated subqueries
- UNION and UNION ALL
- Views
- Common Table Expressions (CTEs)
- Window functions and ranking
- Data manipulation using INSERT, UPDATE, and DELETE

## 💡 Business Questions Explored

Some of the business questions addressed in this project include:

- Which products are ordered most frequently?
- Which brands have the highest average product prices?
- What is the total revenue generated by each product?
- Which stores have the highest inventory value?
- Which products have never received customer reviews?
- What is the monthly and cumulative revenue?
- Which products generate the highest revenue in each category?
- Which customers have reviewed products from multiple brands?

## 📁 Project Files

| File | Description |
|---|---|
| `database_schema_and_data.sql` | Creates database tables and inserts sample data |
| `sql_analysis_queries.sql` | Contains SQL queries for business analysis |

## ▶️ How to Run

1. Clone or download this repository.
2. Open MySQL Workbench.
3. Execute `database_schema_and_data.sql` to create and populate the database.
4. Execute `sql_analysis_queries.sql` to run the analysis queries.
5. Explore the results in MySQL Workbench.

## 🎯 Project Outcome

This project demonstrates practical SQL skills in relational database management, data retrieval, data manipulation, and business analysis. It provides hands-on experience in solving real-world retail business problems using SQL.
